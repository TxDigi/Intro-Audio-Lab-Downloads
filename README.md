## Beta access

Build 12 expires **November 17, 2026 at 6:40 PM Central**. First launch of each build requires internet for signed beta authorization; afterward, the app works offline for up to seven days, subject to expiry. The app starts muted. Set a safe listening level before enabling tone.

Updates are checked at launch and on request. The app prompts you to download them; it does not install them automatically.

The application source repository is private. This repository contains public installer downloads and installation instructions only.
